🔬 Sanity Check & Zero-Trust Guardrails

Why agents cannot self-certify: how deterministic checks enforce safety invariants around stochastic models.

📊 INFOGRAPHIC: The 3-Tier Agent Sanity Funnel Zero-Trust Architecture
🚨 The Risk

LLMs are probabilistic token predictors that will confidently hallucinate invalid items, negative amounts, or skip business rules.

🛡️ The Solution

The Python harness sits outside the LLM. It intercepts raw output, tests every assertion deterministically, and rejects violations.

🔄 The Feedback

Instead of crashing, the harness feeds the exact rejection message back into context, guiding the model to self-correct.

🎯 The Rationale: Why Sanity Checks are Non-Negotiable

In classical programming, functions are deterministic: f(x) produces a predictable output based on rigid logic. In agentic systems, the "function" core is a stochastic transformer model. Even when prompted with instructions like "order at least £50 of groceries", the model may return:

  • Freeform markdown commentary (e.g. "Sure! Here is the order: ```json...") instead of valid schema.
  • Under-budget baskets (in poc/bot.py step 1, the model orders only £10.20 of goods).
  • Invented/hallucinated inventory items not present in the catalog.
  • Infinite loops if tools return unexpected formats or error statuses.
💡 Core Law of Agent Sanity: Never trust the LLM to grade its own homework. An agent cannot declare itself "done" or "valid" without an independent, deterministic harness verifying each invariant.

🔍 The 6 Sanity Checks in poc/bot.py

The reference bot in poc/bot.py implements six distinct sanity checks distributed across every phase of execution:

# Sanity Check Code Location Invariant Enforced Failure Action
1 Context Window Guard tokens(msgs) < 8000 Prevents memory explosion & runaway token billing ❌ Hard Crash Raises AssertionError
2 Max Step Limit for step in range(max_steps): Guarantees termination; caps maximum execution cost ❌ Fail Run Returns False
3 JSON Regex Extraction re.search(r"\{.*\}", text, re.S) Extracts structured payload even from conversational chatter ⚠️ Retry Loop Feeds syntax error to LLM
4 Catalog Whitelist set(b) <= set(PRICE) Rejects hallucinated SKUs not present in price database ⚠️ Reject & Retry Returns error feedback
5 Business Rule Gating basket_total(b) >= SPEC["min_basket_gbp"] Enforces commercial constraints (£50 minimum basket) ⚠️ Reject & Retry Injects feedback: "basket £10.2 is below £50"
6 Acceptance Assertion assert run(), "acceptance test failed" End-to-end integration proof that goal was accomplished ❌ CI / CD Break Blocks deployment

🧪 Live Trace: Sanity Check in Action

Here is how the sanity check caught and corrected a model mistake during our execution of python poc/bot.py: 

tools: ['list_pantry', 'place_order']
[0] tool list_pantry -> {'milk': 0, 'eggs': 2, 'rice': 1, 'yoghurt': 0}

# 🚨 SANITY CHECK TRIPPED HERE:
[1] REJECTED: basket £10.2 is below minimum £50
# Harness appends error to memory: {"role": "error", "content": "basket £10.2 is below minimum £50"}

# 🔄 MODEL RE-EVALUATES WITH CONTEXT:
[2] ORDER OK -> {'status': 'order_placed', 'total': 50.6}
[3] DONE
acceptance test passed -> order_placed

Without the sanity check at step [1], an underfunded order would have been dispatched to the payment gateway, causing financial or logistical errors. The harness caught the mistake deterministically, gave the model constructive feedback, and the model succeeded on step [2].

📋 Agent Sanity Checklist for Production

✅ Production Readiness Gate

  • [ ] Bounded Steps: Is there an unbypassable max_steps or execution timeout?
  • [ ] Budget Limits: Are token counts and tool call counts strictly monitored?
  • [ ] Deterministic Parser: Does output parsing handle markdown code blocks, whitespace, and invalid JSON?
  • [ ] External Verifier: Are financial, database, or API actions guarded by programmatic validators rather than system prompts alone?
  • [ ] Sanitized Feedback: Does the error feedback explain why the action failed without leaking sensitive system data?
  • [ ] End-to-End Acceptance Test: Can the entire agent run against mock tools in CI without human intervention?
